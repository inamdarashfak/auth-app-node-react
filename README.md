# 📝 Secure Notes App (React + Express + SQLite + JWT)

A simple full-stack application to register/login users and perform token-protected CRUD operations for personal notes (with title and description only).

---

## 🚀 Features

- 🔐 User registration and login with bcrypt password hashing
- 🔑 JWT-based token authentication
- 📓 Add, edit, delete, and view notes per user
- ⚙️ SQLite database (lightweight, file-based)
- 🌐 React frontend with Axios & React Router
- 🎨 Basic table UI
